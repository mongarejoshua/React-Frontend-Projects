# Formly Survey Studio

A responsive survey authoring and response dashboard built with React, Vite, Bootstrap, and Recharts.

## Run locally

Use Node.js 20.19+ or 22.12+, then from this project directory run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create and preview a production build:

```bash
npm run build
npm run preview
```

## Features

- Create, edit, duplicate, reorder, publish, and delete surveys and questions.
- Preview surveys and share respondent links, QR codes, and social links.
- Validate and store survey responses, with repeat-submission controls.
- Filter analytics and responses; inspect submissions and export CSV files.
- Persist surveys, responses, and appearance settings in browser local storage.
- Start with three sample surveys and realistic example responses.

Survey data is local to the browser and is not synchronized to a server. Clearing browser storage removes saved surveys and responses.
