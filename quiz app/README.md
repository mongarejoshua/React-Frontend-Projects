# Quiz Master

A responsive, frontend-only quiz application built with React, Vite, Bootstrap 5, and Bootstrap Icons. Quiz attempts, favorite topics, and the theme preference are saved in the current browser's local storage. The leaderboard is example data, not a global ranking.

## Getting started

Requirements: Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create and preview a production build:

```sh
npm run build
npm run preview
```

## Features

- Ten subject categories with 100 original question entries and explanations.
- Category, difficulty, question-count, and question-type quiz settings.
- Randomized questions, answer selection, previous/next navigation, and a 30-second-per-question countdown.
- Automatic score calculation, results summary, and question-by-question answer review.
- Local quiz history, personal best/average, favorite categories, and light/dark theme preference.
- Search and category filters, a rotating daily subject, and a clearly labeled sample leaderboard.

No account or backend is required. Saved data is local to the browser and device.
